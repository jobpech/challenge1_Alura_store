# Challenge Alura Store
## 1. El propósito del análisis realizado.
El propósito de este proyecto es aplicar técnicas de análisis de datos para apoyar la toma de decisiones estratégicas en la cadena Alura Store. A través del estudio de información sobre ingresos, productos, reseñas de clientes y rendimiento general de las tiendas, se busca identificar la sucursal menos eficiente y fundamentar una recomendación clara y objetiva para el Sr. Juan, quien planea vender una de ellas con el fin de iniciar un nuevo emprendimiento.

Este desafío no solo tiene como meta entregar una recomendación sustentada en datos, sino también practicar habilidades clave en ciencia de datos, como la manipulación de archivos CSV con Pandas, la creación de visualizaciones con Matplotlib y la interpretación de métricas de negocio que permitan convertir datos en decisiones estratégicas.
